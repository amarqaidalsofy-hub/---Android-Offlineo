# عمار الصوفي — نظام محاسبي خاص v6
اللغة: العربية
العملة: الريال اليمني

هذه النسخة تضع أساس المحاسبة الفعلية:
- الأصناف: كمية، سعر شراء، سعر بيع، باركود.
- العملاء والموردون.
- الوكلاء: عمولة / مشتريات / النوعان.
- فواتير البيع والشراء.
- الآجل والمدفوع والمتبقي.
- سندات القبض والصرف.
- حركات المخزون.
- كشف حساب الوكيل.
- تقارير المبيعات والمشتريات والأرباح والديون.

ملاحظة: هذه نسخة مشروع تطويرية وليست APK مبنيًا ومختبرًا.


## v10 — إصلاحات سلامة قاعدة البيانات والفواتير
- إنشاء جدول تفاصيل الفاتورة عند التثبيت الجديد، وهو إصلاح يمنع تعطل المرتجعات والفواتير ذات السطور.
- ترقية قاعدة البيانات إلى الإصدار 3 مع الحفاظ على بيانات الإصدارات السابقة.
- جعل تسجيل فاتورة الشراء/البيع وتعديل المخزون ورصيد الوكيل ضمن معاملة واحدة.
- منع البيع بكمية أكبر من المخزون، والتحقق من المدفوع والسعر والكمية.
- رفع رقم إصدار التطبيق إلى 0.6.0.

**تنبيه:** هذه ملفات مشروع مصدرية وليست APK مبنيًا أو مختبرًا على جهاز فعلي.


## وضع التشغيل دون إنترنت
- لا يطلب التطبيق صلاحية الإنترنت في AndroidManifest؛ إدخال البيانات وقراءة قاعدة SQLite محليان على الهاتف.
- الواجهة مضبوطة للعرض من اليمين إلى اليسار باللغة العربية.
- رقم الإصدار المصدر الحالي 0.6.0.
- هذه حزمة مصدر، ويلزم بناؤها باستخدام Android Studio/Gradle ثم تثبيت APK واختباره قبل الاستخدام الفعلي.
- قبل إدخال حسابات حقيقية، اختبر الفواتير والمرتجعات والنسخ الاحتياطي؛ لا تعتمد على هذه النسخة وحدها لحفظ سجلات تجارية مهمة.
